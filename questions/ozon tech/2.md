Напишите запрос для получения n-ной максимальной зарплаты из таблицы Employee .


CREATE TABLE dbo.Salary
(
  Id int NOT NULL PRIMARY KEY 
, Salary numeric(12, 2) NOT NULL
);
GO

INSERT INTO dbo.Salary (Id, Salary)
VALUES
  (1, 100)
, (2, 200)
, (3, 300)
, (4, 100);


Например, для данных приведенных выше, n-ная максимальная зарплата при n=2 будет равна 200. Если нет n-ной зарплаты, то запрос должен вернуть null.
