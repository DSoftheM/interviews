Архитектурная задача (авторизация по SMS)​

  1. Есть система логина по телефону и SMS-коду. Есть таблица с:
  • request_id
  • confirmation_code
  • attempts

Проверка кода происходит в транзакции.

Table:
| reqId: uuid | code: int 000-999 | attempts: int |

[Transactional]
fun check(reqId: uuid, code) {
    val req = getRequest(reqId) ?: throw // select * from req where reqId = :reqId

    if (req.attempts > 3) {
        throw 
    }

    if (req.code != code) {
        updateReq(reqId, req.attempts + 1) // update 
        return false
    }

    return true
}
